# StarGrappler Mod

A grappling hook mod for Hytale that adds exciting traversal mechanics with the Star Grappler, Star Nodes, and Galaxy in a Bottle.

## Features

### Star Grappler
A powerful grappling hook item with two distinct modes:

- **Left-Click (Launch Mode)**: Detects Star Nodes within a 20-block range using a sphere-swept raycast (5 block radius). Launches the player toward the closest Star Node found, automatically unhooking when the player reaches it while preserving momentum.

- **Right-Click (Swing Mode)**: Creates a rope-like connection to a Star Node, allowing players to swing in pendulum motion. Converts player momentum into angular motion for fluid swinging mechanics.

### Star Node
A mystical block made of starlight particles that serves as a grapple point for the Star Grappler. Star Nodes are smaller than normal blocks and use particle effects for their visuals rather than traditional textures. They emit a soft light and can be placed manually or generated by the Galaxy in a Bottle.

### Galaxy in a Bottle
A throwing potion that, when thrown and impacts a surface, generates a field of Star Nodes around the impact location. The Star Nodes are distributed evenly using Poisson disk sampling, ensuring they're spread out but not overlapping.

## Installation

1. Build the mod using Gradle:
   ```bash
   ./gradlew build
   ```

2. The built plugin will be in `build/libs/`

3. Place the plugin JAR file in your Hytale server's plugins directory

## Usage

### Obtaining Items
- **Star Grappler**: Can be obtained through creative mode or custom recipes (to be configured)
- **Star Node**: Can be crafted or obtained through creative mode
- **Galaxy in a Bottle**: Can be crafted or obtained through creative mode

### Using the Star Grappler

1. **Launch Mode (Left-Click)**:
   - Hold the Star Grappler and look in the direction of a Star Node
   - Left-click to launch toward the closest Star Node within range
   - The player will be launched toward the Star Node
   - Upon reaching the Star Node, the connection will automatically unhook, preserving your momentum

2. **Swing Mode (Right-Click)**:
   - Hold the Star Grappler and look in the direction of a Star Node
   - Right-click to create a rope connection to the Star Node
   - Move around to build up swing momentum
   - The connection will maintain until you move too far away or manually disconnect

### Using Galaxy in a Bottle

1. Hold the Galaxy in a Bottle
2. Right-click to throw it
3. When it impacts a surface, it will break and generate a field of Star Nodes around the impact point
4. Use your Star Grappler to traverse between the generated Star Nodes

## Technical Details

### Star Node Detection
The Star Grappler uses a sphere-swept raycast system:
- **Range**: 20 blocks in the player's look direction
- **Detection Radius**: 5 blocks around the ray path
- This allows detection of Star Nodes even if they're not directly in the line of sight, as long as they're within 5 blocks of the ray path

### Physics
- **Launch Mode**: Applies velocity force toward the Star Node using the KnockbackComponent system
- **Swing Mode**: Implements pendulum physics with centripetal force and damping
- Both modes properly handle player collision and momentum preservation

### Particle Effects
- Star Nodes emit particle effects for their visual appearance
- Grappler connections display particle trails from the player to the connected Star Node
- Galaxy in a Bottle impact creates magical particle effects
